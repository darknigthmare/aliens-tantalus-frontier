## Règle d’admission

Référence de l’œuvre/identité → vues suffisantes → asset original approuvé → identité dédiée et provenance → rencontre contextuelle → découverte/sauvegarde/encyclopédie → tests et contrôle visuel. Tant qu’un de ces verrous manque, le dossier reste dans les références, hors pool d’ennemis natifs ; aucun alias vers le mauvais PNG et aucun faux statut `canonExact`.
