## Règle de lecture

Cette matrice consolide **26 conversations exactes**. La colonne « réponse ChatGPT / promesse » décrit ce qui a été proposé, annoncé ou prétendu dans le chat ; elle ne constitue jamais une preuve de livraison. La colonne « runtime réellement branché » ne retient que le code accessible au joueur, sa persistance, ses assets reliés et/ou ses tests.

Statuts stricts :

- **DONE** : contrat complet de la conversation branché, accessible, persistant et testé ;
- **PARTIAL** : au moins une fondation réelle est branchée, mais le contrat du chat reste incomplet ;
- **MISSING** : aucune boucle dédiée correspondant au cœur de la demande ;
- **BLOCKED** : dépendance externe démontrée empêchant le travail.

Les sous-lots terminés ne ferment pas automatiquement une conversation plus large. Ainsi V70 et le gameplay Cargo Brutal peuvent être terminés à leur périmètre tout en restant `PARTIAL` au niveau du chat.

### Règle de production assets

Pour chaque vague, l'ordre doit rester : **contrat runtime → level design/caméra → collisions et échelle → état/sauvegarde → test → assets finaux branchés → QA visuelle**.
