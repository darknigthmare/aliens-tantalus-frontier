01 / OBSERVER

Choisissez une caméra sur le plan. Le capteur balaie toutes les 2,5 secondes. Les échos sont datés, jamais une garantie de sécurité.

02 / GUIDER

Sélectionnez quelqu’un, puis envoyez-le au terminal. Les déplacements sont physiques. Les autres commencent cachés.

03 / SURVIVRE

Une cloison retarde la menace, mais peut être forcée. Variez les leurres et cachez l’équipage. Scellez votre refuge dès l’alerte.
