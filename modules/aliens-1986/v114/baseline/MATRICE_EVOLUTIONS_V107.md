# Périmètre et évolution — V106 Passages RC1 → V107

| Domaine | V106 livrée | V107 vérifiée | Limite |
|---|---|---|---|
| Lieux | 4 secteurs séparés | 6 inspections dont 2 nouveaux lieux ; 5 lieux dans une opération connectée | Pas les 64 plans natifs |
| Passages | Portes internes physiques | 5 liaisons réciproques avec seuil, regroupement et arrivée contrôlée | Coupure de scène ; pas de marche dans un couloir de liaison |
| Groupe | Suivi/attente global | Rallier, Tenir, Couvrir, destinataire individuel ; ressources conservées | Pas d’ordres réseau ou de tactique autonome complète |
| Newt | Présente dans un essai | À recruter dans son lieu, non armée ; escorte exigée pour défense et repli | Aucun scénario du film entièrement reconstruit |
| Portes | État ouvert/fermé immédiat | Ouverture de 0,88 s avec interruption, sauvegarde du geste et fermeture protégée | Pas de soudure ou destruction de porte ajoutée |
| Persistance | Une salle | Toutes les pièces et un registre d’équipe unique | Les combats hors champ sont gelés |
| Inspection | Choix de scène indépendant | Six inspections sans progression d’opération | Changer d’inspection ne sert jamais à compléter un objectif |
| Reprise ancienne | Schéma 106 local | Validation originale puis reprise d’inspection 106 → 107 | Une enveloppe de campagne absente n’est pas inventée |
| Rendu | Procédural stylisé | Nouveaux supports, signalétique des passages, relais et ordres d’équipe | Pas de nouveaux sprites photographiques |
| Preuves | 56 tests Node, 17 contrôles navigateur annoncés | 111 tests Node exécutés ; 31 contrôles navigateur ; 2 opérations automatisées | Les mesures anciennes ne s’ajoutent pas comme nouvelle QA |
| Intégration | Adaptateur manuel / préparation | Adaptateur V106 conservé inchangé | Aucune activation native V107 |

Les règles reprises des autres DLC dans V106 sont poursuivies : géométrie partagée, supports nommés, menus séparés et import préalable validé. Aucune nouvelle version de ces autres DLC n’est prétendue fusionnée dans cette passe.
