# Contrôles manuels cibles — v0.7.0

Ces essais sur ordinateur ou appareil physique ne sont pas déclarés réalisés ici.

1. Ouvrir le HTML sous Windows par double-clic et par le lanceur. Créer une campagne, exporter, fermer puis rouvrir le navigateur ; vérifier la persistance et importer le JSON de secours.
2. Importer un export personnel v6. Vérifier positions, ressources, morts et étape de campagne ; ouvrir F3 sans modifier ces états.
3. Dans la baie, atteindre les portes avant/arrière avec les touches de profondeur ; observer que passer une porte fermée est impossible et que son état est partagé avec l’atlas.
4. Parcourir une salle chargée en mobilier, contourner un obstacle, utiliser un terminal et un casier. Vérifier les pieds sur le sol, les encadrements dans les parois et les plaques lisibles.
5. Consulter un autre secteur via l’atlas sans téléportation ni commande distante autorisée. Revenir au secteur actif puis reprendre la simulation dans son état précédent.
6. En Pharmalab, vérifier les cultures, les épurateurs, le rôle de Studwick et celui de Thorncroft. Comparer les apparences avec une capture authentifiée du jeu original sans confondre nos silhouettes provisoires avec cette référence.
7. Sur petit écran physique, faire défiler les quatre onglets de l’atlas et ouvrir le dernier élément ; revenir au format large, vérifier que la caméra ne déborde pas.
8. Tester un secours, une interruption de portage, une balise à retardement, la fuite d’Amanda, puis exporter/restaurer ces états.

La validation 1:1 exige encore de relever les sept plans officiels et les modèles/tenues de référence. La cohérence interne seule n’établit pas cette fidélité.
